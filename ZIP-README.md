# 📦 SCORM Studio - Ficheiro ZIP da Aplicação

## 🎯 Como Descarregar o ZIP

### Método 1: Download Direto (Recomendado)

1. **Acesse a aplicação** no browser
2. **Login:** `admin` / `admin`
3. **No Dashboard**, clique em **"💾 Download App ZIP"**
4. **Ou acesse diretamente:** `http://localhost:3000/#/download`

O ficheiro `scorm-studio.zip` será descarregado automaticamente!

---

## 🚀 Como Usar Após Descarregar

```bash
# 1. Descompactar
unzip scorm-studio.zip
cd scorm-studio

# 2. Instalar dependências
npm install

# 3. Iniciar aplicação
npm run dev

# 4. Aceder no browser
# http://localhost:3000
# Login: admin / admin
```

## 💡 Dicas

- **Primeiro acesso:** Use as credenciais padrão `admin` / `admin`
- **Criar curso:** Vá para "Courses" → "New Course"
- **Adicionar conteúdo:** Use o editor visual com blocos
- **Exportar SCORM:** Clique em "Export SCORM" no editor
- **Testar:** Use o Mock LMS para validar
- **IA:** Configure o Ollama para geração de conteúdo

## 🐛 Problemas Comuns

### "npm: command not found"
→ Instale o Node.js: https://nodejs.org/

### "Port 3000 already in use"
→ Termine a outra aplicação ou altere a porta em `vite.config.js`

### "Cannot find module"
→ Execute `npm install` novamente

### "Build failed"
→ Verifique se tem espaço em disco suficiente
