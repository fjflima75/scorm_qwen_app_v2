# 📦 Como Descarregar o SCORM Studio

## ✅ Método Recomendado: Download Direto

A aplicação inclui uma página de download integrada que gera o ZIP automaticamente:

### Passo a Passo:

1. **Acesse a aplicação** no seu browser
   - URL: `http://localhost:3000` (ou a porta configurada)

2. **Faça login**
   - Username: `admin`
   - Password: `admin`

3. **No Dashboard, clique em "💾 Download App ZIP"**
   - Ou acesse diretamente: `http://localhost:3000/#/download`

4. **O ficheiro `scorm-studio.zip` será descarregado automaticamente**

---

## 🚀 Como Usar Após Descarregar

### 1. Descompactar o ZIP

**Windows:**
- Clique direito → "Extrair aqui"

**Linux/macOS:**
```bash
unzip scorm-studio.zip
cd scorm-studio
```

### 2. Instalar dependências

```bash
npm install
```

### 3. Iniciar a aplicação

```bash
npm run dev
```

### 4. Aceder

Abra: `http://localhost:3000`

Login: `admin` / `admin`
